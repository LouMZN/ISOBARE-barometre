# Isobare

Quand les données divergent, l'Isobare les relie.

Baromètre du climat économique et financier (États-Unis, zone euro, Japon) : score, régime, valorisation et lecture d'allocation. Projet pédagogique KEDGE BS, cours « Gestion d'actifs et de portefeuille ».

- Site : https://barometre-kedge-3.netlify.app
- Collecte et calculs : `collect/collect.py` (exécuté chaque jour par GitHub Actions), qui produit `site/data.json`
- Page : `site/index.html`
- Référence de méthode : `docs/Barometre_note_de_cadrage_v4.docx`
